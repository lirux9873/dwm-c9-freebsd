# Historical installation reference

The current installation guide is [the FreeBSD guide](../../FREEBSD.md).
The inherited Fedora installer is not supported on FreeBSD.

## Source updates and recovery

The inherited updater and recovery helpers have not been ported. Keep automatic
desktop updates disabled on FreeBSD. Preserve a VM snapshot and existing user
configuration before testing a new build, and use the isolated checks in
[Test VM setup](../../FREEBSD-TEST-HOST.md).

Links to this section in historical release documents describe earlier Fedora
behavior; they are not instructions for updating the FreeBSD desktop.
